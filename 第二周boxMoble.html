第二周 · Box Model

CSS 盒模型：每个元素都是一个矩形盒子，由内到外分成 content、padding、border、margin 四层。

一、四层结构可视化

MARGIN 外边距 · 透明，盒子与外界的距离
BORDER 边框 · 看得见的一圈
PADDING 内边距 · 内容与边框之间的呼吸空间
CONTENT 内容区
文字和图片待在这里

Chrome 开发者工具的 Computed 面板里就是这张图，鼠标悬停页面元素时会用同样的四种颜色标出来。

二、box-sizing：width 到底算不算 padding 和 border

两个盒子都写了 width: 300px; padding: 20px; border: 10px solid，但实际占位不同。

content-box（默认）
300 只是内容区宽度。
实际占位 = 300 + 20×2 + 10×2 = 360px
border-box
300 是内容+padding+border 的总宽。
实际占位就是 300px，内容区自动压缩

实际项目开头都会写一句通配重置，省得每次算宽度：

写法含义
*, *::before, *::after { box-sizing: border-box; }全站统一用 border-box，width 即最终宽度

三、margin 的两个坑

① 相邻兄弟的垂直 margin 会合并：上块 margin-bottom: 30px，下块 margin-top: 20px，中间间距不是 50px 而是取大值 30px。

我 margin-bottom: 30px
我 margin-top: 20px —— 中间实际只有 30px

② 父子 margin 塌陷：子元素的 margin-top 会「穿透」父元素，把父元素一起推下去。给父元素加 padding、border 或 overflow: hidden 可以阻断。

我的 margin-top 被父元素的 1px padding 挡住了，所以没有塌陷出去

横向 margin 不会合并，只有垂直方向会。

四、margin: 0 auto 水平居中

块级元素设了宽度之后，左右 margin 写 auto 就能水平居中。这是最经典的居中手法，本页所有 .panel 都是这么排的。

垂直居中不能用 auto，得靠 flex（align-items: center）或绝对定位 + transform。

五、行内元素的盒模型特殊性

span 这类行内元素：横向的 padding、border、margin 都生效；纵向的 padding 和 border 能画出来但不影响布局（不占位置，会盖住上下行），width 和 height 设了也没用。

解决办法是改成 display: inline-block，它同时具备行内的「不换行」和块级的「可设宽高、纵向 margin 生效」。

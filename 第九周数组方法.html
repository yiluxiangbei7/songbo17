第九周 · 数组方法

增删改查、遍历、排序。重点分清哪些方法会改原数组——这是数组最容易出错的地方。

是否修改原数组？一表看清

方法作用返回值改原数组
push / pop末尾增 / 删新长度 / 被删元素会
unshift / shift开头增 / 删新长度 / 被删元素会
splice任意位置增删改被删元素组成的数组会
sort / reverse排序 / 反转排序后的同一数组会
fill / copyWithin填充 / 内部复制同一数组会
slice截取片段新数组不会
concat合并新数组不会
map / filter / reduce映射 / 过滤 / 累积新值不会
join / toString转字符串字符串不会
indexOf / includes / find查找索引 / 布尔 / 元素不会
forEach遍历undefined不会（除非回调里改）

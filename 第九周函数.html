第九周 · 函数

四种定义方式、返回值、作用域与闭包、箭头函数、以及函数作为一等公民的用法。

一、四种定义方式

二、返回值与提前 return

函数遇到 return 立即结束。没有 return 语句、或 return 后面不带值，返回 undefined。

三、作用域与闭包

内层函数能访问外层函数的变量，即使外层函数已经执行完毕——这就是闭包。它让「私有变量」成为可能。

四、箭头函数

写法更短，且没有自己的 this——它继承定义时所在作用域的 this，这正是它最大的价值。

五、函数是一等公民

函数可以赋值给变量、作为参数传递、作为返回值、存进对象和数组。

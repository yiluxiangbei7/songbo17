二、脚本的三种引入方式

行内：<button onclick="..."> 直接写在标签属性里，只适合一句话，难维护。

内部：<script> 写在 HTML 里，本页用的就是这种。

外部：<script src="js/xxx.js">，可被多个页面复用，正式项目首选。

script 标签的位置：放在 </body> 前，或用 defer 属性。放 <head> 里且不加 defer，脚本执行时 DOM 还没解析完，getElementById 会拿到 null。

三、注释与语句

// 单行注释，/* */ 多行注释。注释是给人看的，也是给几个月后的自己看的。

每条语句以分号结尾（ASI 机制会自动补，但显式写更安全）。JS 区分大小写，log 和 Log 是两个东西。

// 这是本页脚本里真实存在的注释 var greeting = "你好，宋博"; // 字面量：直接写出的值 console.log(greeting);

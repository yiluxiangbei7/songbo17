# AGENTS.md · 项目规则（LLM应用设计）

适用于本目录（24001011017-宋博《高级网页设计I》LLM应用设计实验）下的所有页面、样式与脚本。

## 一、命名与记录

1. 所有 CSS 类名、id 名、JS 变量（含 CSS 自定义属性）统一以 `sjs_` 开头。
2. 每次执行任务前，先向 `songbo_prompt.md` **追加**一条记录，包含：时间、提示词原文、大模型名称；不覆盖历史内容。
3. 第三方依赖只允许出现在 backend（express、dotenv、cors），frontend 一律原生 HTML/CSS/JS，不引入任何框架与 CDN 链接。
4. 接口变更追加到 `backend/songbo_interface.md`，数据表变更追加到 `backend/songbo_database.md`，保证仅凭文档即可重建数据库、复现接口。

## 二、安全

1. API Key、数据库密码等凭据只写在 `backend/.env`，`.env` 必须列入 `.gitignore`，不得出现在代码、文档与提交记录中。

## 三、新建文件必须写注释

1. 文件头注释：作者（宋博）、建立时间（YYYY-MM-DD）、使用模型、功能名称及简介。
2. 每个函数上方写块注释（功能名称、主要功能实现、参数与返回值），关键逻辑行加内联注释。
3. HTML 用分区注释标明结构；CSS 按模块写区块注释；注释一律简体中文，代码标识符保留英文。

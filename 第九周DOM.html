七、性能提示

1. 不要在循环里反复操作 DOM。每次读写都可能触发重排（reflow）或重绘（repaint）。 做法：把 HTML 拼成字符串或用 DocumentFragment 攒起来，最后一次性 append。 2. 读布局属性会强制同步刷新。 offsetTop / offsetWidth / scrollTop / getComputedStyle() 这些一读取，浏览器就得先把待处理的样式算完。 交替「写样式 → 读尺寸 → 再写样式」会造成布局抖动（layout thrashing），应该先集中读、再集中写。 3. 缓存查询结果。 var box = document.getElementById('box'); 查一次存起来，别在循环里反复 getElementById。 4. querySelector 比 getElementsByClassName 灵活，但 getElementsBy* 返回的是「实时集合」， DOM 变了它会自动更新；querySelectorAll 返回的是静态快照。遍历时删除元素要小心实时集合的索引错位。

关于「知乎新闻」

本项目是《高级网页设计I》三级项目，模仿知乎（课程题库 15 号）制作的新闻资讯网站（PC 端）。 数据全部存放在 Supabase 云数据库（PostgreSQL），前端通过 RESTful 接口异步加载， 实现了新闻浏览、话题筛选、关键词搜索、收藏、登录注册、后台管理与数据仪表盘完整闭环。

技术架构

  • 前端：原生 HTML5 / CSS3 / JavaScript（ES6+），无框架、无 UI 组件库、无 CDN
  • 后端：路径 B（BAAS）—— Supabase RESTful API + Auth 认证 + RLS 行级安全
  • 图表：ECharts（本地引入 js/lib/echarts.min.js，非 CDN）
  • LLM：DeepSeek 大模型 AI 摘要，通过 Express 中间层转发，密钥不出服务端
  • 图标：本地 SVG 素材（新闻封面 4 张、话题图标 5 张）

页面清单（前台 8 页 + 后台 2 页）

  • index.html 首页（一级）：轮播图、话题导航、今日热榜
  • list.html 栏目/列表页（二级）：话题 tab 筛选、关键词过滤、分页
  • detail.html 内容/详情页（三级）：URL 传参 ?id=N、评论、收藏、AI 摘要
  • login.html / register.html 登录注册：正则校验、bcrypt 加密、token 保持
  • profile.html 个人中心：用户信息、我的收藏（本地+云端）
  • search.html 搜索结果页：模糊搜索、搜索历史
  • about.html 关于页：本页
  • admin.html 后台管理：3 实体增删改查 + 搜索 + 分页（需登录）
  • dashboard.html 仪表盘：ECharts 图表，接口真实数据驱动（需登录）

JavaScript 效果清单（7 个）

  • ① 轮播图：首页精选新闻自动播放（4s）+ 指示点/箭头手动切换
  • ② tab 选项卡：列表页话题筛选，点击切换高亮并过滤数据
  • ③ 搜索过滤：列表页输入框 input 事件实时过滤标题/摘要
  • ④ 客户端分页：列表页每页 4 条，页码/上一页/下一页切换
  • ⑤ 表单校验：登录/注册页正则校验邮箱、密码强度、两次一致性
  • ⑥ 滚动监听：导航吸顶阴影 + 返回顶部按钮显隐（scroll 事件）
  • ⑦ 本地存储：搜索历史（最多 8 条）与新闻收藏（localStorage）

动画清单（3 处，覆盖 3 种实现方式）

  • ① transition：新闻卡片 hover 上浮 + 导航吸顶阴影（0.3s ease）
  • ② animation：轮播指示点呼吸光晕（songbo_breath，1.5s infinite）+ 弹窗弹出 songbo_pop（0.25s ease）
  • ③ canvas：首页粒子连线背景（requestAnimationFrame 逐帧绘制）

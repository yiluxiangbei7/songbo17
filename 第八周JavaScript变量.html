二、var / let / const 的区别

关键字作用域重复声明重新赋值变量提升
var函数作用域允许允许提升并初始化为 undefined
let块级作用域 {}报错允许提升但不初始化（暂时性死区）
const块级作用域 {}报错不允许提升但不初始化

const 锁的是「绑定」不是「内容」：用 const 声明的对象和数组，内部属性照样能改，只有整体重新赋值才会报错。

三、命名规则

只能包含字母、数字、下划线、美元符号；不能以数字开头；区分大小写；不能用保留字（var、function、class 等）。

惯例用小驼峰 studentName；常量全大写加下划线 MAX_COUNT；构造函数与类用大驼峰 Person。

合法： userName _private $price count2 宋博姓名(可用但不建议) 非法： 2count（数字开头） my-name（减号会被当运算符） var（保留字） my name（有空格）

四、数据类型与 typeof

基本类型 6 种：Number、String、Boolean、Undefined、Null、Symbol；引用类型统称 Object。

flex-grow · 分配剩余空间

蓝块 flex-grow: 2，橙块和绿块各 flex-grow: 1，剩余空间按 2:1:1 分。

flex-basis · 起始尺寸

蓝块设 flex-basis: 220px 且 flex-grow: 0，宽度固定不参与伸缩；其余两块平分剩下的。

order · 视觉排序

HTML 里顺序是 A、B、C，靠 order 让 C 排到最前。注意这只改视觉顺序，不改 DOM 与 Tab 键焦点顺序。

A (order:3)B (order:2)C (order:1)

flex-wrap + flex-direction: column

上排 flex-wrap: wrap，窗口变窄时自动折行；下排 flex-direction: column 改成竖排，主轴变为垂直方向。

第八周 · Promise 对象

Promise 解决「回调地狱」：把异步操作的三种状态（pending / fulfilled / rejected）显式表达出来，让流程可以链式书写。

一、基本用法与三种状态

状态一旦从 pending 变为 fulfilled 或 rejected 就不可逆，之后再调用 resolve / reject 都无效。

二、链式调用：消灭回调地狱

每个 then 返回一个新的 Promise，所以能一直往下接。return 普通值会被自动包装成 resolved 状态；throw 则跳到后面的 catch。

三、错误处理 catch

catch 能捕获链上任意环节抛出的错误，包括 then 回调里同步抛出的异常。链尾放一个 catch 是最佳实践。

四、并发控制：all / race / allSettled

五、async / await 语法糖

await 让异步代码读起来像同步代码，错误处理直接用 try...catch。注意 await 只能用在 async 函数内部。

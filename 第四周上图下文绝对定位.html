第四周 · 上图下文绝对定位

核心口诀「父相子绝」：父元素设 position: relative 当参照物，子元素设 position: absolute 相对它定位，脱离文档流盖在上面。

为什么要父元素先 relative？因为 absolute 会一路往上找「最近的已定位祖先」，找不到就以浏览器窗口为基准。 给卡片加 position: relative 就把定位范围锁在这张卡片里，角标和文字条才不会跑位。

  • 层级 z-index

    奋斗者号

    多个绝对定位元素重叠时，用 z-index 决定谁在上面（数值大的在上）。

    z-index 只对已定位元素生效，static 元素设了也没用。

    z-index
  • left: 0 right: 0

    FAST 天眼

    同时写 left: 0 和 right: 0，元素宽度就自动拉满参照物，不用算百分比。

    同理 top: 0; bottom: 0 能拉满高度；四个都写 0 再配 margin: auto 可实现绝对居中。

    双向拉伸
  • flex + absolute

    爱达·魔都号

    外层用 flex 排三列卡片，卡片内部用绝对定位做叠加，两者分工不冲突。

    这是实际项目里最常见的组合：flex/grid 管整体布局，absolute 管局部叠加。

    组合用法

四种 position 取值对照

static（默认）：top/left 无效，按正常文档流排列
static
relative：相对「自己原本的位置」偏移，原位仍被保留（占着坑）

top:20 left:20
absolute：相对最近的已定位祖先偏移，脱离文档流，不占位置

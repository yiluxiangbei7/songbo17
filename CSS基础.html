CSS 基础

文字属性、颜色写法、常用单位与边框圆角的基础练习。本页同时演示了行内样式、内部样式表与外部样式表三种引入方式的差别。

一、文字属性

font-weight: 700 — 加粗

font-style: italic — 倾斜

text-decoration: underline — 下划线

text-decoration: line-through — 删除线

text-transform turns lowercase into uppercase

text-indent: 2em — 首行缩进两个字符，中文段落常用这个值，因为它跟着字号走。

text-align: center — 水平居中

text-shadow: 2px 2px 0 — 文字投影

行内样式：直接写在标签的 style 属性里，优先级最高，但不利于复用。

二、颜色的四种写法

#2364aa
rgb(35,100,170)
rgba(...,.6)
hsl(212,51%,40%)

前两个是完全相同的颜色，第三个多了 60% 不透明度，第四个用色相/饱和度/亮度描述，调亮调暗比十六进制直观。

三、常用长度单位

width: 200px — 固定像素，不随窗口变化

width: 50% — 相对父元素宽度

width: 12em — 相对自身字号（16px × 12）

width: 14rem — 相对根元素字号，不受嵌套影响

width: 40vw — 相对视口宽度的 40%

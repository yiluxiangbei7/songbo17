第四周 · Flex 上图下文

用 display: flex + flex-wrap: wrap + gap 排图文卡片，子项定宽 300px 做到一行三张，窗口变窄自动折行。

  • 复兴号动车组

    上图下文的典型结构：img 占满卡片宽度，下面接标题与说明文字。

    flex: 0 0 300px

  • C919 大飞机

    object-fit: cover 让不同比例的图裁切后仍然等高，卡片不会参差不齐。

    object-fit

  • 天宫空间站

    父元素 overflow: hidden 配合子元素圆角，图片不会顶出圆角外。

    overflow

  • 奋斗者号

    第四张自动折到第二行，这就是 flex-wrap: wrap 的效果。

    flex-wrap

  • FAST 天眼

    gap: 20px 同时管横行与竖列间距，不用再给 li 加 margin 去处理末列多余空白。

    gap

  • 爱达·魔都号

    悬停时 transform: translateY(-5px) 抬起卡片，加阴影强化层次。

    transform

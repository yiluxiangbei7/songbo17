CSS 样式优先级

层叠（Cascade）三原则：先比权重，权重相同比出现顺序，!important 是唯一的例外。

一、权重计算：四位数字 (行内, id, class, 标签)

下面这行文字同时被 4 条规则命中，最终显示绿色。 id 规则(0,1,0,0)？不，它设的是黑色但被更具体的选择器压过？看表格。

我被 #target / .box / p / .panel .box 四条规则同时选中

实际生效的是 .panel .box（权重 0,0,2,0）。
但 #target 权重是 0,1,0,0，比它高——所以最终颜色其实是 id 规则的 #17324d 深墨色。 这正是权重的意义：数字大者胜，与书写顺序无关。

二、权重对照表

选择器写法行内idclass标签权重值
p00010,0,0,1
.box00100,0,1,0
.panel .box00200,0,2,0
#target01000,1,0,0 ✓
style="..." 行内10001,0,0,0
!important不参与比较，直接置顶最高

三、同权重比顺序：后写的赢

本页 <link> 引入的外部样式表在前，<style> 内部样式表在后。两者权重相同时，内部样式表的规则生效。

这也是为什么浏览器默认样式总被我们覆盖——它的权重最低且最先加载。

四、!important 与继承

这行用了 !important，显示金色，压过了所有普通规则。

颜色可以从父元素继承下来（color 是可继承属性）。

这行写了 color: initial，拒绝继承，回到浏览器默认的黑色。

可继承的多是文字类属性：color、font-*、line-height、text-align。盒模型属性（width、margin、border）默认不继承。

用 float 与 margin-left 搭一个 header / nav / aside+main / footer 的经典页面骨架。

侧边栏 ASIDE

  • float: left 定宽 200px
  • 高度由内容撑开
  • 右边界用虚线分隔
  • 不参与右侧文字环绕

主内容区 MAIN

右侧不浮动，改用 margin-left: 200px 让出侧边栏的宽度。这样主区宽度会随窗口自适应，比给主区也设 float + 定宽更省事。

父容器 .body-wrap 加了 overflow: hidden，用来触发 BFC 清除内部浮动，否则父元素高度会塌陷成 0，下面的 footer 会顶上来。

页面底部 FOOTER
这一步的坑：浮动元素会脱离文档流，父元素量不到它的高度。三种常见解法——父元素 overflow: hidden、末尾加空 div 配 clear: both、或用 ::after 伪元素清除。本页用第一种，代码最少。
